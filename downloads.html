The whole thing at once

The workbook holds every table on its own sheet, and the report is the written version with the findings, the open gaps and the drafted records requests.

How to read a CSV

Every file is UTF-8 with a header row and one record per line. Identifier columns end in _id and join across files: source_id joins anything to the source ledger, bill_id joins bills, amendments, votes and testimony, and issue_id joins everything to an issue. Dates are YYYY-MM-DD; a blank date means the source record did not state one, never that the event has no date.

Which files are newest

The CSV files are rebuilt with the site. bills.csv, votes.csv, member_votes.csv, legislators.csv, amendments.csv and testimony.csv cover all 231 cannabis bills from 2012 to 2026. The workbook and the PDF report were written earlier, when the bill table held 23 bills; use the CSVs where they disagree.

Two things to know before you publish from these files

Statutory text in these files came from the enacted public acts, and the reliability_tier column tells you how far each row can be pushed. Read the guardrails first: the record does not support every claim these columns will tempt you into.
